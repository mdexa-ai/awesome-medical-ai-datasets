# Contributing

## English

This list is generated from the verified records of the Mdexa database, so rows are not edited by hand.

- **Add a dataset:** submit it at https://mdexa.com/submit/, or call the MCP tool `request_dataset` on `https://mcp.mdexa.com/mcp`. Requests are queued by demand; a dataset appears here after Mdexa has verified it.
- **Correct a row:** open an issue in [mdexa-ai/database](https://github.com/mdexa-ai/database/issues) with a link to the source that supports the correction. The card is corrected first, and this list follows at the next release.

## 中文

本清单由 Mdexa 数据库的已核实记录生成，清单行不手工修改。

- **增加数据集：** 在 https://mdexa.com/zh/submit/ 提交，或在 `https://mcp.mdexa.com/mcp` 调用 MCP 工具 `request_dataset`。请求按需求排队；Mdexa 核实之后，数据集才会出现在这里。
- **更正：** 在 [mdexa-ai/database](https://github.com/mdexa-ai/database/issues) 开 issue，并附支持更正的来源链接。先改信息卡，本清单在下次发布时同步。
